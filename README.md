# Data Science Lab

A collection of end-to-end data-science / machine-learning mini-projects — each one lives in its own folder with its own notebook, dataset, and `README.md`.

 **Every project below is one click away.** Click *Open in Colab* to run a notebook live in your browser, or *nbviewer* to read the rendered notebook (code, charts and results) without installing anything.

## Setup

```bash
git clone https://github.com/RoBiul-Hasan-Jisan/data-science-lab.git
cd data-science-lab
pip install -r requirements.txt
```

See [`requirements.txt`](https://github.com/RoBiul-Hasan-Jisan/data-science-lab/blob/main/requirements.txt) for the exact Python packages used.

## Repo structure

Each project folder contains:

- `README.md` — quick summary + one-click links (this page's format, repeated per folder)
- `description.md` — the full write-up: dataset info, EDA insights, model results
- `*.ipynb` — the Jupyter notebook with the actual analysis/model
- a `.csv`/`.xlsx` dataset file
